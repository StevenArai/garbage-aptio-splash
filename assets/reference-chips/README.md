# Reference chip outlines

This folder holds an original diagram of common SPI flash packages.
The diagram is original work under CC0 1.0.
It has no logo, no brand mark, and no photo.

Files:

- `package-outlines.svg`: SOP8, SSOP8, WSON8, USON8, and SOP16 outlines.

Use the diagram to help the user find the SPI chip.
Do not use it to identify the chip model.
The chip model comes from the silkscreen or from software.

The diagram is not to scale.
The pin 1 dot is a convention, not a guarantee.
The real chip can have a different pin 1 mark.
